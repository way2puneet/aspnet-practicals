Implement HTML controls

Plain HTML input, check box and drop-down, turned into server controls.

Book: Program 2.6No database needed
AimUse HTML server controls to accept a student’s name, a library card choice and a city, and show the details when Submit is clicked.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • The difference between an ordinary HTML control and an HTML server control.
  • How adding runat="server" and an id lets C# use a plain HTML element.
  • Reading HTML server controls in C#: .Value, .Checked and .InnerText.
  • Handling a click on the server with onserverclick.

The idea in simple words

Normal HTML tags like <input> and <select> are handled only by the browser. The server cannot read or change them.

Add two attributes, id and runat="server", and the same tag becomes an HTML server control. Now C# can read it like an object. This is useful when you already have an HTML page and want to add server code to it.

HTML tagBecomes this class on the serverRead it with
<input type="text">HtmlInputText.Value
<input type="checkbox">HtmlInputCheckBox.Checked
<select>HtmlSelect.Value, .Items, .SelectedIndex
<span>HtmlGenericControl.InnerText, .Style

Code

Add a Web Form named HtmlControlsDemo.
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="HtmlControlsDemo.aspx.cs" Inherits="StudentPortal.HtmlControlsDemo" %><!DOCTYPE html><html xmlns="http://www.w3.org/1999/xhtml"><head runat="server">    <title>HTML Server Controls</title></head><body>    <form id="form1" runat="server">        <div>            <h2>Library Membership</h2>            Name: <input type="text" id="txtStudent" runat="server" maxlength="40" />            <br /><br />            <input type="checkbox" id="chkLibrary" runat="server" /> Library Card Required            <br /><br />            City:            <select id="selCity" runat="server">                <option value="LDH">Ludhiana</option>                <option value="ASR">Amritsar</option>                <option value="JAL">Jalandhar</option>            </select>            <br /><br />            <input type="submit" id="btnSubmit" runat="server" value="Submit"                onserverclick="btnSubmit_ServerClick" />            <br /><br />            <span id="spnResult" runat="server"></span>        </div>    </form></body></html>
using System; namespace StudentPortal{    public partial class HtmlControlsDemo : System.Web.UI.Page    {        protected void btnSubmit_ServerClick(object sender, EventArgs e)        {            string name = txtStudent.Value.Trim();             if (name == "")            {                spnResult.InnerText = "Please enter your name.";                spnResult.Style["color"] = "red";                return;            }             string card = chkLibrary.Checked ? "Yes" : "No";            string city = selCity.Items[selCity.SelectedIndex].Text;             spnResult.InnerText = "Name: " + name +                " | Library Card: " + card +                " | City: " + city +                " (Code: " + selCity.Value + ")";            spnResult.Style["color"] = "green";        }    }}

How it works

  1. <input type="text" id="txtStudent" runat="server" maxlength="40" />A normal HTML text box. Because of runat="server", C# can read it as txtStudent.
  2. <select id="selCity" runat="server"> <option value="LDH">Ludhiana</option> ...Each option has text (Ludhiana) shown to the user and a value (LDH) sent to the server.
  3. <input type="submit" ... onserverclick="btnSubmit_ServerClick" />HTML server controls use onserverclick (not OnClick) to name the C# method that runs on the server.
  4. string name = txtStudent.Value.Trim();HTML text boxes use .Value. (Web server controls like asp:TextBox use .Text.)
  5. string card = chkLibrary.Checked ? "Yes" : "No";The ? : operator is a short if-else: "Yes" if the box is ticked, otherwise "No".
  6. string city = selCity.Items[selCity.SelectedIndex].Text;Gets the text of the selected option. selCity.Value gives its value, such as ASR.
  7. spnResult.InnerText = ...; spnResult.Style["color"] = "green";InnerText sets the text inside the span. Style sets its CSS, here the colour.

Common mistakes

  • Using .Text on an HTML text box. HTML server controls use .Value.
  • Writing onclick instead of onserverclick. onclick runs JavaScript in the browser, not C# on the server.
  • Forgetting the id attribute. Without an id, C# has no name to use for the control.

Viva questions

What is an HTML server control?
An ordinary HTML element with the attributes id and runat="server". ASP.NET creates an object for it on the server, so C# can use it.
Name two differences between HTML server controls and web server controls.
HTML server controls are plain HTML tags (like <input>) with simple properties such as Value. Web server controls start with asp: (like <asp:TextBox>) and give more properties and events, such as validation and AutoPostBack.
Which namespace contains HTML server control classes?
System.Web.UI.HtmlControls.
What is the use of onserverclick?
It connects a click on an HTML button to a C# method that runs on the server.
What is the difference between Text and Value of a select option?
The text (Amritsar) is shown to the user. The value (ASR) is what the program uses.
