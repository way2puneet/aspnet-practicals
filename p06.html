Design a web page using rich controls, validation controls and file concepts

Three small pages: a Calendar, a fully validated registration form, and an assignment upload.

Book: Programs 3.1, 3.3 and 3.7No database needed
AimUse a rich control (Calendar), check user input with validation controls, and work with files by uploading an assignment to the server.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • Rich controls: the Calendar control and its SelectionChanged event.
  • Validation controls: Required, Range, Regular Expression, Compare, Custom and ValidationSummary.
  • Checking Page.IsValid before using any input.
  • File concepts: FileUpload, checking type and size, and saving with SaveAs() using the Path and Directory classes.

The idea in simple words

The syllabus puts three topics in one program, so this page has three parts. Make each one as a separate Web Form in the same project.

Part A: Calendar (rich control)

A rich control does a lot of work with one tag. The Calendar draws a whole month, lets the user move between months and pick a date, all without extra code.

Code

Add a Web Form named DateSelection.
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="DateSelection.aspx.cs" Inherits="StudentPortal.DateSelection" %><!DOCTYPE html><html xmlns="http://www.w3.org/1999/xhtml"><head runat="server">    <title>Date Selection</title></head><body>    <form id="form1" runat="server">        <div>            <h2>Select Your Date of Birth</h2>            <asp:Calendar ID="calDOB" runat="server" FirstDayOfWeek="Monday"                TitleStyle-BackColor="LightSteelBlue" SelectedDayStyle-BackColor="Navy"                OnSelectionChanged="calDOB_SelectionChanged">            </asp:Calendar>            <br />            <asp:Label ID="lblDate" runat="server" Text="No date selected."></asp:Label>        </div>    </form></body></html>
using System; namespace StudentPortal{    public partial class DateSelection : System.Web.UI.Page    {        protected void Page_Load(object sender, EventArgs e)        {            if (!IsPostBack)            {                calDOB.VisibleDate = new DateTime(2006, 1, 1);            }        }         protected void calDOB_SelectionChanged(object sender, EventArgs e)        {            DateTime dob = calDOB.SelectedDate;            lblDate.Text = "Date of Birth: " + dob.ToString("dd MMMM yyyy") +                " (" + dob.DayOfWeek + ")";        }    }}

How it works

  1. <asp:Calendar ID="calDOB" ... FirstDayOfWeek="Monday" TitleStyle-BackColor="LightSteelBlue" SelectedDayStyle-BackColor="Navy"One tag draws the full calendar. The style properties set the colour of the title row and of the selected day.
  2. calDOB.VisibleDate = new DateTime(2006, 1, 1);VisibleDate decides which month is shown. A date of birth is in the past, so the calendar opens at January 2006 instead of today.
  3. OnSelectionChanged="calDOB_SelectionChanged"This event runs when the user clicks a date.
  4. lblDate.Text = "Date of Birth: " + dob.ToString("dd MMMM yyyy") + " (" + dob.DayOfWeek + ")";SelectedDate gives the clicked date. "dd MMMM yyyy" formats it as 15 March 2006, and DayOfWeek gives the day name.

Part B: Validation controls

Validation controls check what the user typed. They check in the browser first (fast, no postback) and again on the server (safe, because browser checks can be switched off). Each validator watches one control, named in ControlToValidate.

using System;using System.Web.UI.WebControls; namespace StudentPortal{    public partial class ValidatedRegistration : System.Web.UI.Page    {        protected void cvPassword_ServerValidate(object source, ServerValidateEventArgs args)        {            string password = args.Value;            bool hasLetter = false, hasDigit = false;             foreach (char ch in password)            {                if (char.IsLetter(ch)) hasLetter = true;                if (char.IsDigit(ch)) hasDigit = true;            }             args.IsValid = password.Length >= 8 && hasLetter && hasDigit;        }         protected void btnRegister_Click(object sender, EventArgs e)        {            if (!Page.IsValid)            {                lblResult.Text = "";                return;            }             lblResult.Text = "Registration successful for " + Server.HtmlEncode(txtName.Text.Trim()) +                " (Roll No. " + txtRollNo.Text + ", " + ddlCourse.SelectedValue + ").";        }         protected void btnReset_Click(object sender, EventArgs e)        {            txtName.Text = "";            txtRollNo.Text = "";            txtAge.Text = "";            ddlCourse.SelectedIndex = 0;            txtEmail.Text = "";            txtMobile.Text = "";            lblResult.Text = "";        }    }}

How it works

  1. <asp:RequiredFieldValidator ... ControlToValidate="txtName" Text="*" ErrorMessage="Name is required." />Text (*) appears next to the field. ErrorMessage appears in the ValidationSummary at the top.
  2. ValidationExpression="[A-Z]{3}\d{3}"A regular expression: [A-Z]{3} means three capital letters, \d{3} means three digits. So BCA101 is valid, bca101 is not.
  3. <asp:RangeValidator ... MinimumValue="17" MaximumValue="30" Type="Integer" />Type="Integer" is important. Without it, the values are compared as text, and "4" would be counted as more than "30".
  4. <asp:RequiredFieldValidator ... ControlToValidate="ddlCourse" InitialValue="0" />For a drop-down, "required" means "not still on the first item". The first item has value 0, so InitialValue="0".
  5. <asp:CompareValidator ... ControlToCompare="txtPassword" Operator="Equal" />Checks that the confirm box equals the password box.
  6. args.IsValid = password.Length >= 8 && hasLetter && hasDigit;The CustomValidator runs your own C# rule on the server, in cvPassword_ServerValidate. Set args.IsValid to true or false.
  7. if (!Page.IsValid) { ...; return; }Page.IsValid is true only if every validator passed. Always check it before using the data.
  8. <asp:Button ID="btnReset" ... CausesValidation="false" />The Reset button skips validation, so it can clear the form even when the fields are empty or wrong.

Part C: File upload (file concepts)

The FileUpload control shows a Browse button. When the form is posted, the chosen file travels to the server. The C# code checks it and saves it with SaveAs(). The classes Path and Directory from System.IO help with file names and folders.

Code

Add a Web Form named UploadAssignment.
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="UploadAssignment.aspx.cs" Inherits="StudentPortal.UploadAssignment" %><!DOCTYPE html><html xmlns="http://www.w3.org/1999/xhtml"><head runat="server">    <title>Upload Assignment</title></head><body>    <form id="form1" runat="server">        <div>            <h2>Assignment Submission</h2>            Roll Number:            <asp:TextBox ID="txtRollNo" runat="server" MaxLength="6"></asp:TextBox>            <asp:RequiredFieldValidator ID="rfvRollNo" runat="server" ControlToValidate="txtRollNo" ErrorMessage="Roll number is required." ForeColor="Red" Display="Dynamic"></asp:RequiredFieldValidator>            <asp:RegularExpressionValidator ID="revRollNo" runat="server" ControlToValidate="txtRollNo"                ValidationExpression="[A-Z]{3}\d{3}" ErrorMessage="Enter a roll number such as BCA101."                ForeColor="Red" Display="Dynamic"></asp:RegularExpressionValidator>            <br /><br />            Assignment File (PDF or Word, maximum 2 MB):            <asp:FileUpload ID="fuAssignment" runat="server" />            <br /><br />            <asp:Button ID="btnUpload" runat="server" Text="Upload" OnClick="btnUpload_Click" />            <br /><br />            <asp:Label ID="lblMessage" runat="server"></asp:Label>        </div>    </form></body></html>
using System;using System.IO; namespace StudentPortal{    public partial class UploadAssignment : System.Web.UI.Page    {        private const int MaxFileSize = 2 * 1024 * 1024;     // 2 MB in bytes        private readonly string[] allowedExtensions = { ".pdf", ".doc", ".docx" };         protected void btnUpload_Click(object sender, EventArgs e)        {            lblMessage.Text = "";             if (!Page.IsValid)            {                return;            }             if (!fuAssignment.HasFile)            {                ShowMessage("Please select a file to upload.", false);                return;            }             string originalName = Path.GetFileName(fuAssignment.FileName);            string extension = Path.GetExtension(originalName).ToLower();             if (Array.IndexOf(allowedExtensions, extension) < 0)            {                ShowMessage("Only PDF and Word files (.pdf, .doc, .docx) are allowed.", false);                return;            }             int size = fuAssignment.PostedFile.ContentLength;            if (size > MaxFileSize)            {                ShowMessage("The file is larger than 2 MB. Please upload a smaller file.", false);                return;            }             string folder = Server.MapPath("~/App_Data/Uploads");            string savedName = txtRollNo.Text.Trim() + extension;             try            {                Directory.CreateDirectory(folder);                fuAssignment.SaveAs(Path.Combine(folder, savedName));                 ShowMessage("Assignment uploaded successfully.<br />" +                    "Original file: " + Server.HtmlEncode(originalName) + "<br />" + "Saved as: " + savedName + "<br />" +                    "Size: " + (size / 1024.0).ToString("0.0") + " KB", true);            }            catch (Exception ex)            {                ShowMessage("The file could not be saved: " + Server.HtmlEncode(ex.Message), false);            }        }         private void ShowMessage(string message, bool success)        {            lblMessage.ForeColor = success ? System.Drawing.Color.Green : System.Drawing.Color.Red;            lblMessage.Text = message;        }    }}

How it works

  1. private const int MaxFileSize = 2 * 1024 * 1024;1 KB = 1024 bytes and 1 MB = 1024 KB, so 2 MB = 2,097,152 bytes.
  2. if (!fuAssignment.HasFile)HasFile is false if the user clicked Upload without choosing a file.
  3. string extension = Path.GetExtension(originalName).ToLower();Path.GetExtension() gives the ending, such as .pdf. ToLower() makes .PDF and .pdf the same.
  4. if (Array.IndexOf(allowedExtensions, extension) < 0)Array.IndexOf() returns -1 if the extension is not in the allowed list.
  5. int size = fuAssignment.PostedFile.ContentLength;The size of the file in bytes, compared with the 2 MB limit.
  6. string folder = Server.MapPath("~/App_Data/Uploads"); Directory.CreateDirectory(folder);Server.MapPath() turns a website path into a real folder path on the server. CreateDirectory() makes the folder if it does not exist yet.
  7. fuAssignment.SaveAs(Path.Combine(folder, savedName));Saves the file as the roll number plus the extension, for example BCA101.pdf. Path.Combine() joins folder and file name correctly.
  8. try { ... } catch (Exception ex) { ... }If saving fails (for example, no permission), the error is shown in a friendly way instead of crashing the page.

Common mistakes

  • Getting the error "UnobtrusiveValidationMode requires a ScriptResourceMapping for 'jquery'". Add the setting from Setup to Web.config.
  • Leaving out Type="Integer" on a RangeValidator. The numbers are then compared as text and give wrong results.
  • Not checking Page.IsValid in the button’s Click code. The CustomValidator runs only on the server, so its result is known only through Page.IsValid.
  • Expecting the Calendar to open at the selected year. Set VisibleDate in Page_Load inside if (!IsPostBack).
  • Uploading a file bigger than 4 MB. ASP.NET refuses it before your code runs, because the default request limit is 4 MB.

Viva questions

What are rich controls? Give examples.
Controls that provide a complete feature with a single tag, such as Calendar, AdRotator and FileUpload.
Name the validation controls of ASP.NET.
RequiredFieldValidator, CompareValidator, RangeValidator, RegularExpressionValidator, CustomValidator and ValidationSummary.
Why is validation done on both the client and the server?
Client-side checks are fast and avoid a postback. Server-side checks are needed for safety, because a user can switch off JavaScript and skip the client checks.
What is the use of InitialValue?
It tells a RequiredFieldValidator which value counts as "not filled", such as the value of a "-- Select --" item in a drop-down.
What is the use of CausesValidation="false"?
It lets a button, such as Reset or Cancel, post the page without running the validators.
What is Server.MapPath()?
It converts a virtual path of the website, such as ~/App_Data/Uploads, into the real physical folder path on the server.
Why is the uploaded file saved in App_Data?
ASP.NET never sends files from App_Data to browsers, so uploaded files cannot be opened directly by typing a web address.
