Develop a ticket-reservation application using ASP.NET controls

A bus ticket booking page that brings together most controls of the course.

Book: New programNo database needed
AimBuild a bus ticket reservation page that takes passenger details, route, journey date, bus type and seats, checks them, and shows a ticket with the fare.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • Using many controls together in one real application: TextBox, DropDownList, Calendar, RadioButtonList, CheckBox, Button, Panel.
  • Validation of a full form, including CompareValidator with Operator="NotEqual".
  • Blocking past dates in a Calendar with the DayRender event.
  • Doing a calculation (fare, concession, total) and showing the result in a Panel.

The idea in simple words

This program is a small project. It uses ideas from Programs 1 to 6:

Part of the formControlCheck
Passenger nameTextBoxRequired
Mobile numberTextBoxRequired, 10 digits starting 6 to 9
From / ToTwo DropDownListsBoth required, and not the same city
Journey dateCalendarToday to 30 days ahead (checked in C#)
Bus typeRadioButtonListRequired. The item value is the fare
SeatsDropDownList1 to 6
Student concessionCheckBox10% off

Fare = seats × fare per seat. If the student box is ticked, 10% is taken off. A random PNR number is made for each booking.

How it works

  1. <asp:CompareValidator ... ControlToValidate="ddlTo" ControlToCompare="ddlFrom" Operator="NotEqual" />A CompareValidator can check more than equality. NotEqual makes sure the destination is different from the starting city.
  2. <asp:ListItem Value="600">AC (Rs. 600)</asp:ListItem>The text is shown to the user; the value holds the fare per seat, so C# can read the fare directly with SelectedValue.
  3. <asp:RequiredFieldValidator ... ControlToValidate="rblBusType" />A RequiredFieldValidator also works with a RadioButtonList: it fails if no option is chosen.
  4. if (e.Day.Date < DateTime.Today || e.Day.Date > DateTime.Today.AddDays(30)) { e.Day.IsSelectable = false;DayRender runs once for every day cell while the calendar is drawn. Past days and days more than 30 days ahead are made unclickable and grey.
  5. if (calJourney.SelectedDate == DateTime.MinValue)Validators cannot check a Calendar, so C# checks it. If no date was clicked, SelectedDate is DateTime.MinValue.
  6. int total = seats * farePerSeat; int concession = chkStudent.Checked ? total * 10 / 100 : 0;The fare calculation. The ? : operator gives 10% of the total if the student box is ticked, otherwise 0.
  7. string pnr = "PNR" + random.Next(100000, 1000000);Random.Next(a, b) gives a whole number from a up to b - 1, so the PNR always has 6 digits.
  8. pnlTicket.Visible = true;The ticket is built in a Label inside a Panel with a dashed border. The Panel is hidden until a booking succeeds.
  9. calJourney.SelectedDates.Clear(); rblBusType.ClearSelection();Reset clears the calendar’s selection and the radio button list. Reset has CausesValidation="false", so it works even when the form has errors.

Common mistakes

  • Trying to put a RequiredFieldValidator on the Calendar. A Calendar cannot be validated by validators; check SelectedDate in C#.
  • Forgetting the Value on the bus type items. Then int.Parse(rblBusType.SelectedValue) fails, because the value would be the text "AC (Rs. 600)".
  • Comparing e.Day.Date with DateTime.Now instead of DateTime.Today. Now includes the time, so today itself would be blocked.
  • Reset button without CausesValidation="false". It then cannot clear a form that has errors.

Viva questions

Which controls are used in this application?
TextBox, DropDownList, Calendar, RadioButtonList, CheckBox, Button, Label, Panel and the validation controls (RequiredField, RegularExpression, Compare, ValidationSummary).
What is the DayRender event?
An event of the Calendar that runs once for each day cell while the calendar is drawn. It is used to change how a day looks or to make it unselectable.
How is the same city stopped in From and To?
With a CompareValidator: ControlToValidate is the To list, ControlToCompare is the From list, and Operator is NotEqual.
What does DateTime.MinValue mean for a Calendar?
It is the value of SelectedDate when no date has been selected (1 January 0001).
How would you save bookings permanently?
Create a Booking table in the database and run an INSERT command with ADO.NET when the ticket is booked, as in Program 10.
