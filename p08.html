Perform data binding with web controls

A drop-down filled from the database, labels filled with <%# %>, and a list of students.

Book: New program (based on Section 4.8)Needs CollegeDB database
AimFill a DropDownList with courses from the database, and when a course is chosen, bind its details to Labels and its students to a ListBox.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • What data binding is: connecting a control to data so that it shows the data by itself.
  • List binding: DataSource, DataTextField, DataValueField and DataBind() on DropDownList and ListBox.
  • Simple binding: putting one value into a Label with a <%# %> expression.
  • Why nothing appears until DataBind() is called.

The idea in simple words

Instead of adding list items one by one (like Program 5), you give the control a whole table of data and say "show this". That is data binding. It has two types:

TypeWhat is boundUsed here on
List bindingMany rows to a control that shows many itemsDropDownList (courses), ListBox (students)
Simple bindingOne value to one propertyLabels showing name, duration and fee

For a list, you set two field names: DataTextField (what the user sees, the full course name) and DataValueField (what the program gets back, the course code).

The syllabus program 7 bound data with no code. This program does it in C#, so you can see each step.

Before you run: this program uses both tables of CollegeDB (Course and Student). See Setup.

Add a Web Form named CourseInfo.

using System;using System.Configuration;using System.Data;using System.Data.SqlClient;using System.Web.UI.WebControls; namespace StudentPortal{    public partial class CourseInfo : System.Web.UI.Page    {        private string cs = ConfigurationManager.ConnectionStrings["CollegeDB"].ConnectionString;         // These values are shown on the page through <%# %> expressions        protected string CourseName = "";        protected int Duration = 0;        protected decimal AnnualFee = 0;         protected void Page_Load(object sender, EventArgs e)        {            if (!IsPostBack)            {                SqlDataAdapter da = new SqlDataAdapter(                    "SELECT CourseCode, CourseName FROM Course ORDER BY CourseCode", cs);                DataTable courses = new DataTable();                da.Fill(courses);                 // List binding: one list item for each row of the table                ddlCourse.DataSource = courses;                ddlCourse.DataTextField = "CourseName";     // shown to the user                ddlCourse.DataValueField = "CourseCode";    // returned by SelectedValue                ddlCourse.DataBind();                 ddlCourse.Items.Insert(0, new ListItem("-- Select Course --", ""));            }        }         protected void ddlCourse_SelectedIndexChanged(object sender, EventArgs e)        {            string code = ddlCourse.SelectedValue;            if (code == "")            {                pnlDetails.Visible = false;                return;            }             // 1. Read the selected course into the three fields            using (SqlConnection con = new SqlConnection(cs))            using (SqlCommand cmd = new SqlCommand(                "SELECT CourseName, DurationYears, AnnualFee FROM Course WHERE CourseCode = @Code", con))            {                cmd.Parameters.AddWithValue("@Code", code);                con.Open();                using (SqlDataReader reader = cmd.ExecuteReader())                {                    if (reader.Read())                    {                        CourseName = reader.GetString(0);                        Duration = reader.GetInt32(1);                        AnnualFee = reader.GetDecimal(2);                    }                }            }             // 2. Read the students of the course into a table            SqlDataAdapter da = new SqlDataAdapter(                "SELECT RollNo, StudentName FROM Student WHERE Course = @Code ORDER BY StudentName", cs);            da.SelectCommand.Parameters.AddWithValue("@Code", code);            DataTable students = new DataTable();            da.Fill(students);             lstStudents.DataSource = students;            lstStudents.DataTextField = "StudentName";            lstStudents.DataValueField = "RollNo";             // 3. One call binds everything inside the panel:            //    the three labels (simple binding) and the list box (list binding)            pnlDetails.Visible = true;            pnlDetails.DataBind();             lblCount.Text = "Total students: " + students.Rows.Count;        }    }}

How it works

  1. ddlCourse.DataSource = courses; ddlCourse.DataTextField = "CourseName"; ddlCourse.DataValueField = "CourseCode"; ddlCourse.DataBind();List binding. The table of courses is given to the drop-down. Each row becomes one item: the user sees the course name, and SelectedValue gives the code (BCA, MCA...). DataBind() is what actually copies the data into the control.
  2. ddlCourse.Items.Insert(0, new ListItem("-- Select Course --", ""));After binding, a prompt item is added at position 0, with an empty value.
  3. if (!IsPostBack) { ... }The courses are loaded only on the first visit. The list remembers its items after that, so there is no need to ask the database again.
  4. Text='<%# CourseName %>'Simple binding. A <%# %> expression in the page. It shows the value of the field CourseName from the C# class. Note the single quotes around the attribute.
  5. protected string CourseName = ""; protected int Duration = 0; protected decimal AnnualFee = 0;The fields used by the expressions. They must be protected or public so the page can see them.
  6. CourseName = reader.GetString(0); Duration = reader.GetInt32(1); AnnualFee = reader.GetDecimal(2);The selected course is read with a SqlDataReader and stored in the three fields.
  7. lstStudents.DataSource = students; lstStudents.DataTextField = "StudentName";The students of the course are prepared for list binding into the ListBox.
  8. pnlDetails.DataBind();One call binds every control inside the panel: the three labels (their <%# %> expressions are worked out now) and the ListBox.

Common mistakes

  • Forgetting DataBind(). Setting DataSource alone shows nothing, and <%# %> labels stay empty.
  • Writing Text="<%# "Rs. " + ... %>" with double quotes outside. Use single quotes around the attribute when the expression contains double quotes.
  • Making the fields private. The page cannot read private fields in <%# %> expressions.
  • Binding the course list on every postback. It resets the user’s choice. Keep it inside if (!IsPostBack).

Viva questions

What is data binding?
Connecting a property or the items of a control to a source of data, so that the control shows the data automatically when binding is performed.
What are the two types of data binding?
Simple data binding (one value to one property, using <%# %>) and list (data source) binding (many rows to a control such as DropDownList or GridView).
Difference between DataTextField and DataValueField?
DataTextField is the field shown as the text of each item. DataValueField is the field stored as the value, returned by SelectedValue.
When must DataBind() be called?
When data is given through the DataSource property in code, and when <%# %> expressions are used. It is not needed when DataSourceID is used.
What does Page.DataBind() do?
It binds every control on the page, including all <%# %> expressions.
