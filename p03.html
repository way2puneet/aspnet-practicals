Implement server controls

A feedback form where server controls react to typing, ticking and clicking.

Book: Program 2.5No database needed
AimBuild a feedback form that uses the TextChanged, CheckedChanged and Click events of server controls.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • Server controls have events, just like buttons in a desktop program.
  • The three common events: Click, TextChanged and CheckedChanged.
  • Why AutoPostBack="True" is needed to handle an event immediately.
  • Showing and hiding a group of controls with a Panel and its Visible property.

The idea in simple words

A server control is a control with runat="server". It is an object on the server, so it has properties (like Text) and events (like Click).

A button always sends the page to the server. A text box or check box normally does not. If you set AutoPostBack="True", it posts the page back as soon as its value changes, and its event runs straight away.

ControlEventWhen it runs
TextBoxTextChangedAfter the text changes and you click outside the box
CheckBoxCheckedChangedWhen the box is ticked or unticked
ButtonClickWhen the button is clicked

How it works

  1. <asp:RadioButton ... GroupName="Rating" Checked="true" />Radio buttons with the same GroupName form one group, so only one can be selected. "Good" is selected at the start.
  2. <asp:TextBox ID="txtComments" ... AutoPostBack="True" OnTextChanged="txtComments_TextChanged">When the comment changes and the user leaves the box, the page posts back and txtComments_TextChanged runs.
  3. lblCount.Text = "Characters typed: " + txtComments.Text.Length;Length gives the number of characters in the text.
  4. <asp:Panel ID="pnlEmail" runat="server" Visible="false">A Panel is a box that holds other controls. When it is not visible, nothing inside it is sent to the browser.
  5. pnlEmail.Visible = chkReply.Checked;In chkReply_CheckedChanged: show the e-mail box when the check box is ticked, hide it when unticked.
  6. string rating = "Good"; if (rbExcellent.Checked) ... else if (rbAverage.Checked) ...In btnSubmit_Click: find which radio button is selected and build the thank-you message.

Common mistakes

  • Expecting TextChanged to run on every key press. It runs only after the text changes and the box loses focus (you click outside it).
  • Forgetting AutoPostBack="True". Then TextChanged and CheckedChanged wait until the next button click.
  • Using different GroupName values for the radio buttons, so more than one can be selected.

Viva questions

What is a server control?
A control with runat="server" that is created as an object on the server, with properties, methods and events, and that produces HTML for the browser.
What does AutoPostBack do?
When it is True, the control posts the page back to the server immediately when its value changes, so its event runs at once.
Which event of a TextBox is used in this program?
TextChanged. It runs when the text has changed between two postbacks.
What is the difference between Visible and Enabled?
When Visible is false, the control is not sent to the browser at all. When Enabled is false, it is shown but greyed out and cannot be used.
What is the use of GroupName?
Radio buttons with the same GroupName belong to one group, so only one of them can be selected at a time.
