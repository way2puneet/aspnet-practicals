Practical Programs

All 14 programs from the practical syllabus (Course Code 325C61). Each one has the complete code, a simple explanation, and a working preview you can try in this page.

First time? Read Setup once. It shows how to create the project and the CollegeDB database. Programs 7 to 11 and 13 use this database.

Programs

  1. 01Gain exposure to web applications and development tools Program 2.2Your first Web Form: type a name, click a button, see a message.
  2. 02Implement HTML controls Program 2.6Plain HTML input, check box and drop-down, turned into server controls.
  3. 03Implement server controls Program 2.5A feedback form where server controls react to typing, ticking and clicking.
  4. 04Develop a web application using web controls Program 2.4A student registration form built with TextBox, RadioButton, CheckBox, Button and Label.
  5. 05Develop a web application using list controls Program 2.7Pick a course and the subject list fills itself. Uses DropDownList, RadioButtonList and ListBox.
  6. 06Design a web page using rich controls, validation controls and file concepts Programs 3.1, 3.3 and 3.7Three small pages: a Calendar, a fully validated registration form, and an assignment upload.
  7. 07Develop a web application using data controls Program 4.5Choose a course and a GridView lists its students. No C# code at all.
  8. 08Perform data binding with web controls New program (based on Section 4.8)A drop-down filled from the database, labels filled with <%# %>, and a list of students.
  9. 09Perform data binding with data controls Program 4.6Fill a GridView from the database in C#, with a name search.
  10. 10Develop a database application to perform insert, update and delete operations New program (combines Programs 4.1, 4.4 and 5.1)One form to add, find, change and remove student records with ADO.NET commands.
  11. 11Develop a database application using data controls to perform insert, delete, edit, paging and sorting New program (data-control version of Programs 5.1 to 5.3)GridView and DetailsView with one SqlDataSource. Almost everything works without code.
  12. 12Implement XML classes Programs 5.5 and 5.4Create an XML file with XmlWriter, and read one with XmlReader.
  13. 13Implement authentication and authorization Program 5.7 and Section 5.10A login page with Forms Authentication, and an Admin folder only the admin can open.
  14. 14Develop a ticket-reservation application using ASP.NET controls New programA bus ticket booking page that brings together most controls of the course.
