Implement XML classes

Create an XML file with XmlWriter, and read one with XmlReader.

Book: Programs 5.5 and 5.4No database needed
AimUse the XmlWriter class to create Courses.xml, and the XmlReader class to read Students.xml and show it as a table.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • The structure of an XML document: declaration, root element, elements, attributes, text.
  • Writing XML with XmlWriter: WriteStartElement, WriteAttributeString, WriteElementString, WriteEndElement.
  • Reading XML with XmlReader: the Read() loop and NodeType.
  • Where XML files are kept in a website: the App_Data folder, found with Server.MapPath().

The idea in simple words

XML stores data as text with tags you invent yourself, such as <Student> and <Marks>. Every XML file has exactly one root element that holds everything else.

XmlWriter and XmlReader both work forward-only: they move through the file from top to bottom, one node at a time. This makes them fast and light on memory.

ClassDoesCreated with
XmlWriterWrites a new XML file, one node at a timeXmlWriter.Create(path, settings)
XmlReaderReads an XML file, one node at a timeXmlReader.Create(path, settings)
XmlDocumentLoads the whole file as a tree that can be changednew XmlDocument() + Load()

Both pages use using System.Xml;. Make them as two Web Forms in the same project.

Part A: Create an XML file with XmlWriter

Code

Add a Web Form named XmlWriterDemo.
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="XmlWriterDemo.aspx.cs" Inherits="StudentPortal.XmlWriterDemo" %><!DOCTYPE html><html xmlns="http://www.w3.org/1999/xhtml"><head runat="server">    <title>Writing XML with XmlWriter</title></head><body>    <form id="form1" runat="server">        <div>            <h2>Create Courses.xml</h2>            <asp:Button ID="btnCreate" runat="server" Text="Create XML File" OnClick="btnCreate_Click" />            <br /><br />            <asp:Label ID="lblMessage" runat="server" Font-Bold="True"></asp:Label>            <pre><asp:Literal ID="litXml" runat="server" Mode="Encode"></asp:Literal></pre>        </div>    </form></body></html>
Make sure the project has an App_Data folder (right-click project → Add → Add ASP.NET Folder → App_Data).
using System;using System.IO;using System.Xml; namespace StudentPortal{    public partial class XmlWriterDemo : System.Web.UI.Page    {        protected void btnCreate_Click(object sender, EventArgs e)        {            string path = Server.MapPath("~/App_Data/Courses.xml");             string[] codes = { "BCA", "BSc IT", "MCA" };            string[] names = { "Bachelor of Computer Applications",                    "B.Sc. Information Technology",                    "Master of Computer Applications" };            int[] years = { 3, 3, 2 };            int[] fees = { 45000, 40000, 60000 };             XmlWriterSettings settings = new XmlWriterSettings();            settings.Indent = true;             using (XmlWriter writer = XmlWriter.Create(path, settings))            {                writer.WriteStartDocument();                writer.WriteComment("Courses offered by the college");                writer.WriteStartElement("Courses");                 for (int i = 0; i < codes.Length; i++)                {                    writer.WriteStartElement("Course");                    writer.WriteAttributeString("Code", codes[i]);                    writer.WriteElementString("Name", names[i]);                    writer.WriteElementString("DurationYears", years[i].ToString());                    writer.WriteElementString("AnnualFee", fees[i].ToString());                    writer.WriteEndElement();     // </Course>                }                 writer.WriteEndElement();         // </Courses>                writer.WriteEndDocument();            }             lblMessage.Text = "Courses.xml created with " + codes.Length + " courses.";            litXml.Text = File.ReadAllText(path);        }    }}

How it works

  1. string path = Server.MapPath("~/App_Data/Courses.xml");The full folder path on the server where the new file will be saved.
  2. settings.Indent = true;Puts each element on its own line with spaces in front, so the file is easy to read.
  3. writer.WriteStartDocument();Writes the first line: <?xml version="1.0" encoding="utf-8"?>.
  4. writer.WriteStartElement("Courses");Opens the root element. Everything else goes inside it.
  5. writer.WriteStartElement("Course"); writer.WriteAttributeString("Code", codes[i]);Inside the loop: opens a <Course> element and gives it an attribute, Code="BCA".
  6. writer.WriteElementString("Name", names[i]);Writes a complete small element in one go: <Name>Bachelor of Computer Applications</Name>.
  7. writer.WriteEndElement(); // </Course>Closes the last opened element. Every Start needs a matching End.
  8. litXml.Text = File.ReadAllText(path);Reads the new file back and shows it. The Literal has Mode="Encode", so the tags are shown as text instead of being treated as HTML.

Common mistakes
  • Missing App_Data folder. XmlWriter.Create() fails with "Could not find a part of the path". Add the folder first.
  • An unclosed or misspelt tag in Students.xml, such as <Name>...</name>. XML is case-sensitive, and XmlReader stops with an XmlException.
  • Forgetting WriteEndElement() for an element you started. Every Start needs an End.
  • Using a Label instead of a Literal with Mode="Encode" to show the XML. The browser then treats the tags as HTML and shows only the text inside them.


Viva questions
What is XML?
eXtensible Markup Language: a text format for storing and exchanging data using tags defined by the user.
What is the root element?
The single element that contains all other elements of an XML document. Every XML document must have exactly one.
What is the difference between an element and an attribute?
An element is a tag pair with content, like <Name>Aman</Name>. An attribute is a name-value pair inside the start tag, like RollNo="BCA101".
Difference between XmlReader and XmlDocument?
XmlReader reads forward-only, one node at a time, using very little memory, and cannot change the file. XmlDocument loads the whole file into memory as a tree that can be read in any order and modified.
What is the use of NodeType?
It tells what kind of node the reader is on, such as Element (start tag), Text, EndElement or Comment.
Which namespace contains the XML classes?
System.Xml.
