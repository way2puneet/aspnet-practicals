Develop a web application using list controls

Pick a course and the subject list fills itself. Uses DropDownList, RadioButtonList and ListBox.

Book: Program 2.7No database needed
AimCreate a course-selection form where choosing a course fills a list of its subjects, and Submit shows the course, semester and selected subjects.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • The list controls: DropDownList, ListBox, RadioButtonList (and CheckBoxList).
  • Adding items in markup with asp:ListItem and in C# with Items.Add().
  • Reading the choice with SelectedIndex, SelectedItem and SelectedValue.
  • Why filling a list is done inside if (!IsPostBack).

The idea in simple words

A list control shows a collection of ListItem objects. Each item has Text (what the user sees) and Value (what the program uses).

The course list has AutoPostBack="True". So as soon as a course is chosen, the page goes to the server, the SelectedIndexChanged event runs, and C# fills the subject list.

How it works

  1. if (!IsPostBack) { ddlCourse.Items.Add(new ListItem("BCA", "BCA")); ... }IsPostBack is false only on the first visit. Items are added once; after that ASP.NET remembers them (in ViewState). Without this check, the list would get duplicate items on every click.
  2. <asp:DropDownList ID="ddlCourse" ... AutoPostBack="True" OnSelectedIndexChanged="ddlCourse_SelectedIndexChanged">Choosing a course posts the page back immediately and runs ddlCourse_SelectedIndexChanged.
  3. lstSubjects.Items.Clear(); ... lstSubjects.Items.Add("Programming in C");The old subjects are removed, then the subjects of the chosen course are added.
  4. <asp:ListBox ... SelectionMode="Multiple" Rows="4">A ListBox shows several items at once. Multiple lets the user select more than one with Ctrl.
  5. if (ddlCourse.SelectedIndex == 0 || rblSemester.SelectedIndex == -1)Index 0 is "-- Select Course --", and -1 means no semester was chosen. Either case shows a message.
  6. foreach (int index in lstSubjects.GetSelectedIndices())GetSelectedIndices() returns the positions of all selected subjects. The loop adds each one to the summary.

Common mistakes

  • Filling the drop-down outside if (!IsPostBack). Every postback then adds the same items again.
  • Forgetting AutoPostBack="True" on the course list, so the subjects appear only after Submit is clicked.
  • Using SelectedItem.Text when nothing is selected. It is null and causes an error. Check SelectedIndex first.

Viva questions

Name the four list controls.
DropDownList, ListBox, CheckBoxList and RadioButtonList.
What is a ListItem?
One item of a list control. It has a Text (shown) and a Value (used by the program), and a Selected property.
Difference between SelectedIndex, SelectedItem and SelectedValue?
SelectedIndex is the position (from 0, or -1 if none). SelectedItem is the selected ListItem object. SelectedValue is only its Value.
When is SelectedIndexChanged raised?
When the selection in a list control changes between two postbacks. With AutoPostBack="True" it is handled immediately.
How do you allow selecting many items in a ListBox?
Set SelectionMode="Multiple", then read them with GetSelectedIndices() or by checking each item’s Selected property.
