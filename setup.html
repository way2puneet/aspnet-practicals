Before you start

Setup

Do this once. After that, every program is just: add a page, paste the code, press Ctrl + F5.

1. Install the software

SoftwareWhy you need it
Visual Studio 2022 Community (free)The IDE where you write and run the programs. While installing, tick the workload ASP.NET and web development.
SQL Server Express (free)The database used by Programs 7 to 11 and 13. Install SQL Server Management Studio (SSMS) too, to run SQL scripts easily.

2. Create the project

  1. Open Visual Studio and choose Create a new project.
  2. Select ASP.NET Web Application (.NET Framework) with the C# language.
  3. Name the project StudentPortal and choose .NET Framework 4.8.
  4. Choose the Empty template, tick Web Forms, and click Create.
Why the name StudentPortal matters: every program in the book starts with namespace StudentPortal. If your project has another name, change StudentPortal in both files of each page (the Inherits attribute in the .aspx file and the namespace in the .aspx.cs file).

3. Add a program to the project

  1. In Solution Explorer, right-click the project → Add → Web Form. Give it the exact page name used by the program, for example Welcome.
  2. Open Welcome.aspx, switch to Source view, delete everything, and paste the .aspx code.
  3. Open Welcome.aspx.cs (expand the page in Solution Explorer), delete everything, and paste the .aspx.cs code.
  4. Right-click the page → Set as Start Page, then press Ctrl + F5. The page opens in your browser.

Visual Studio keeps a third file, Welcome.aspx.designer.cs, up to date by itself. You never edit it.

4. Replace Web.config

Open Web.config in the project and replace it with the file below. It stores the database connection string and switches off a setting that otherwise stops validation controls from working in an Empty project.

Project root. Program 13 uses its own version of this file with security settings.
<?xml version="1.0" encoding="utf-8"?><configuration>  <connectionStrings>    <add name="CollegeDB"         connectionString="Data Source=.\SQLEXPRESS;Initial Catalog=CollegeDB;Integrated Security=True"         providerName="System.Data.SqlClient" />  </connectionStrings>  <appSettings>    <add key="ValidationSettings:UnobtrusiveValidationMode" value="None" />  </appSettings>  <system.web>    <compilation debug="true" targetFramework="4.8" />    <httpRuntime targetFramework="4.8" />  </system.web></configuration>
Using LocalDB instead of SQL Server Express? Change the data source to Data Source=(localdb)\MSSQLLocalDB. Everything else stays the same.

5. Create the CollegeDB database

Open SSMS, connect to .\SQLEXPRESS, click New Query, paste this script and press F5. It creates the database, two tables and the sample records used in the book.

Run once in SQL Server Management Studio.

If something goes wrong

Error messageWhat to do
WebForms UnobtrusiveValidationMode requires a ScriptResourceMapping for 'jquery'Your Web.config is missing the ValidationSettings:UnobtrusiveValidationMode line. Use the Web.config above.
Could not load type 'StudentPortal.Welcome'The namespace or class name does not match the page. Check the Inherits attribute and the class name, then rebuild with Ctrl + Shift + B.
The name 'txtName' does not exist in the current contextThe control ID in the .aspx file and the name used in C# are different, or the page was pasted in Design view. Paste in Source view and save both files.
A network-related or instance-specific error occurred while establishing a connection to SQL ServerSQL Server is not running, or the server name in the connection string is wrong. Check the name you use to connect in SSMS.
Cannot open database "CollegeDB"The database script has not been run yet. Run CollegeDB.sql.
