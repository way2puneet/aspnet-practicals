Develop a web application using web controls

A student registration form built with TextBox, RadioButton, CheckBox, Button and Label.

Book: Program 2.4No database needed
AimCreate a registration form that accepts a student’s name, roll number, gender, address and facilities, and shows a summary when Register is clicked.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • The standard web controls: TextBox, RadioButton, CheckBox, Button, Label.
  • Making a multi-line text box with TextMode="MultiLine".
  • Reading .Text and .Checked in C# and building a result.
  • Using return to stop early when required data is missing.

The idea in simple words

Web controls are the asp: controls you drag from the Standard group of the Toolbox. Each one becomes a normal HTML element in the browser. For example, asp:TextBox becomes <input>, and asp:Label becomes <span>.

The form is arranged in a two-column HTML table: labels on the left, controls on the right. When Register is clicked, C# reads every control and writes a summary into a label.

using System; namespace StudentPortal{    public partial class Registration : System.Web.UI.Page    {        protected void btnRegister_Click(object sender, EventArgs e)        {            string name = txtName.Text.Trim();            string rollNo = txtRollNo.Text.Trim();             if (name == "" || rollNo == "")            {                lblSummary.ForeColor = System.Drawing.Color.Red;                lblSummary.Text = "Name and Roll Number are required.";                return;            }             string gender = "Not selected";            if (rbMale.Checked)            {                gender = "Male";            }            else if (rbFemale.Checked)            {                gender = "Female";            }             string facilities = "";            if (chkHostel.Checked)            {                facilities += "Hostel ";            }            if (chkTransport.Checked)            {                facilities += "College Transport";            }            if (facilities == "")            {                facilities = "None";            }             lblSummary.ForeColor = System.Drawing.Color.Green;            lblSummary.Text = "<b>Registration Successful</b><br />" +                "Name: " + Server.HtmlEncode(name) + "<br />" +                "Roll Number: " + Server.HtmlEncode(rollNo) + "<br />" +                "Gender: " + gender + "<br />" +                "Address: " + Server.HtmlEncode(txtAddress.Text.Trim()) + "<br />" +                "Facilities: " + facilities;        }    }}

How it works

  1. <asp:RadioButton ID="rbMale" ... GroupName="Gender" />Male and Female share the group name Gender, so only one can be selected.
  2. <asp:TextBox ID="txtAddress" ... TextMode="MultiLine" Rows="3" Columns="30">TextMode="MultiLine" turns the text box into a bigger box for an address. Rows and Columns set its size.
  3. if (name == "" || rollNo == "") { ...; return; }|| means OR. If either value is empty, show a red message and return stops the method.
  4. string gender = "Not selected"; if (rbMale.Checked) gender = "Male"; else if ...Start with a default value, then change it based on which radio button is checked.
  5. if (chkHostel.Checked) facilities += "Hostel ";+= adds text to the end. Each ticked check box adds its facility. If none are ticked, the result is "None".
  6. lblSummary.Text = "<b>Registration Successful</b><br />" + ...A Label can hold HTML, so <b> makes text bold and <br /> starts a new line. Typed text goes through Server.HtmlEncode() for safety.

Common mistakes

  • Copying the Male radio button line from the book without the opening <. The control then appears as plain text.
  • Giving the two radio buttons different GroupName values, so both can be selected.
  • Using = instead of == inside an if. = assigns a value; == compares.

Viva questions

What are standard (web) controls?
The basic asp: controls such as Label, TextBox, Button, CheckBox, RadioButton, HyperLink, Image and Panel, used to show information and accept input.
What HTML does an asp:Label produce?
A <span> element. A TextBox produces <input> (or <textarea> when it is multi-line).
What are the three values of TextMode?
SingleLine (default), MultiLine (for addresses and comments) and Password (hides the typed characters).
Difference between CheckBox and RadioButton?
Many check boxes can be ticked at the same time. Only one radio button in a group can be selected.
What does Trim() do?
It removes spaces from the start and end of a string, so a value of only spaces is treated as empty.
