Perform data binding with data controls

Fill a GridView from the database in C#, with a name search.

Book: Program 4.6Needs CollegeDB database
AimDisplay the Student table in a GridView by binding it in C#, and let the user search students by part of their name.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • Binding a data control in code: DataSource + DataBind().
  • Choosing your own GridView columns with AutoGenerateColumns="False" and BoundField.
  • Filling a DataTable with a SqlDataAdapter.
  • Searching safely with LIKE and a parameter.

The idea in simple words

In Program 7 the GridView bound itself through DataSourceID. Here you do it yourself in C#, which gives more control:

  1. Run a SELECT query and fill a DataTable (a table in memory) using a SqlDataAdapter.
  2. Give the table to the grid: gvStudents.DataSource = table;
  3. Call gvStudents.DataBind(); The grid creates one row for each record.

All the work is in one method, BindGrid(). The page calls it on the first visit, on Search, and on Show All.

Before you run: create the CollegeDB database as shown in Setup.

How it works

  1. <asp:GridView ID="gvStudents" ... AutoGenerateColumns="False" DataKeyNames="StudentID" ...>AutoGenerateColumns="False" means only the columns you list are shown. DataKeyNames remembers each row’s StudentID without showing it.
  2. <asp:BoundField DataField="RollNo" HeaderText="Roll No" />A BoundField shows one field of the data. DataField is the column name in the table; HeaderText is the heading shown.
  3. <HeaderStyle BackColor="Navy" ForeColor="White" ... /> <AlternatingRowStyle BackColor="#EEEEEE" />Style tags: a navy heading row and light grey shading on every second row.
  4. if (!IsPostBack) { BindGrid(""); }On the first visit, show all students (an empty filter matches every name).
  5. cmd.Parameters.AddWithValue("@Name", "%" + nameFilter + "%");In SQL, % means "any characters". So %ar% matches every name that contains "ar" anywhere. The value is passed as a parameter, never joined into the SQL text, which keeps the query safe.
  6. SqlDataAdapter da = new SqlDataAdapter(cmd); DataTable table = new DataTable(); da.Fill(table);The adapter opens the connection, runs the query, copies the rows into the DataTable and closes the connection by itself.
  7. gvStudents.DataSource = table; gvStudents.DataBind();The binding. Without DataBind() the grid stays empty.
  8. lblCount.Text = "Records found: " + table.Rows.Count;Rows.Count gives the number of rows in the table.

Common mistakes

  • Leaving AutoGenerateColumns as True while also adding BoundFields. Every column then appears twice.
  • A DataField name that is not in the SELECT query, which gives "A field or property with the name ... was not found".
  • Building the query by joining text, like "... LIKE '%" + txtSearch.Text + "%'". This allows SQL injection. Always use a parameter.

Viva questions

What is a DataTable?
An in-memory table of rows and columns from the System.Data namespace. It holds data after the database connection is closed.
What does SqlDataAdapter.Fill() do?
It opens the connection (if closed), runs the SELECT command, copies the rows into a DataTable or DataSet, and closes the connection again.
Difference between DataSource and DataSourceID?
DataSource is set in code to an object such as a DataTable, and DataBind() must be called. DataSourceID is set to the ID of a data source control, and binding happens automatically.
What is a BoundField?
A GridView column that displays the value of one data field as text. DataField names the field and HeaderText sets the heading.
What is the use of DataKeyNames?
It names the key field (such as StudentID) whose value is stored for every row, so code can find the record of a row even though the field is not shown.
