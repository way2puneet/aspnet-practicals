Develop a database application using data controls to perform insert, delete, edit, paging and sorting

GridView and DetailsView with one SqlDataSource. Almost everything works without code.

Book: New program (data-control version of Programs 5.1 to 5.3)Needs CollegeDB database
AimUse a GridView and a DetailsView connected to one SqlDataSource to insert, delete, edit, page and sort student records.
What you learnCodeHow it worksTry itCommon mistakesViva

What you will learn

  • Giving a SqlDataSource all four commands: Select, Insert, Update and Delete.
  • Switching on GridView features with properties: AllowSorting, AllowPaging, and a CommandField for Edit and Delete.
  • Adding new records with a DetailsView in Insert mode.
  • Handling database errors in the ...Inserted, ...Updated and ...Deleted events.

The idea in simple words

The book (Programs 5.1 to 5.3) does deleting, editing, sorting and paging with C# code. The syllabus asks for the same using data controls, so here the controls do the work:

TaskHow it is switched onWho runs the SQL
SortingAllowSorting="True" and a SortExpression on each columnSqlDataSource (sorts in memory)
PagingAllowPaging="True" PageSize="4"SqlDataSource
Edit<asp:CommandField ShowEditButton="True" />SqlDataSource UpdateCommand
Delete<asp:CommandField ShowDeleteButton="True" />SqlDataSource DeleteCommand
InsertA DetailsView with DefaultMode="Insert"SqlDataSource InsertCommand

Both the GridView and the DetailsView use the same data source. When a record is added, the data source tells the GridView, and the grid refreshes by itself.

Before you run: create the CollegeDB database as shown in Setup.

How it works

  1. UpdateCommand="UPDATE Student SET StudentName = @StudentName, ... WHERE StudentID = @StudentID"Each command uses parameters named after the fields. When you click Update, the GridView fills them with the new values from the text boxes.
  2. <asp:Parameter Name="Semester" Type="Int32" />Lists each parameter with its type, so "3" typed in a text box is turned into the number 3.
  3. DataKeyNames="StudentID"The key of each row. It fills @StudentID in the Update and Delete commands, so the right record is changed.
  4. AllowSorting="True" ... <asp:BoundField ... SortExpression="Marks" />Column headings with a SortExpression become links. Click once for ascending order, click again for descending.
  5. AllowPaging="True" PageSize="4"Shows 4 rows at a time and adds page numbers below the grid.
  6. <asp:BoundField DataField="RollNo" ... ReadOnly="True" />The roll number cannot be edited. In edit mode it stays as plain text, and the other cells become text boxes.
  7. <asp:DetailsView ... DefaultMode="Insert" ... OnItemInserted="dvNewStudent_ItemInserted">A DetailsView shows one record as a form. In Insert mode it is always an empty form with an Insert link.
  8. if (e.Exception != null) { ...; e.ExceptionHandled = true; e.KeepInInsertMode = true; }If the database rejects the record (same roll number, empty field, marks over 100), show a message instead of an error page, and keep the typed values.

Common mistakes

  • Forgetting DataKeyNames="StudentID". Update and Delete then have no value for @StudentID and change nothing.
  • Column headings that are not links. A column can be sorted only if it has a SortExpression and the grid has AllowSorting="True".
  • Parameter names that do not match the field names. The GridView passes values named after DataField, so @StudentName must match DataField="StudentName".
  • Expecting the GridView to insert records. A GridView can edit and delete, but not insert; use a DetailsView or FormView for that.

Viva questions

Which events of GridView are used for editing?
RowEditing (enter edit mode), RowUpdating / RowUpdated (save changes), and RowCancelingEdit (cancel). With a SqlDataSource, the grid handles them by itself.
What is the use of CommandField?
A GridView column that shows command links or buttons such as Select, Edit, Update, Cancel and Delete.
What is paging? Which properties enable it?
Showing records a few at a time across several pages. It is enabled with AllowPaging="True", and PageSize sets the number of rows per page.
What is DetailsView?
A data-bound control that shows one record at a time as a two-column form. It can insert, edit and delete records.
Can a GridView insert records?
No. A GridView supports select, edit, update, delete, paging and sorting, but not insert. A DetailsView or FormView is used to insert.
What does e.ExceptionHandled = true do?
It tells ASP.NET that the error has been dealt with, so no error page is shown.
